# Decide whether HiveMind retires its lessons folder

project-docs 9.0.0 retired its `lesson` document type in favour of playbooks.
HiveMind keeps its own Lessons Learned folder, an Operator group that
`hivemind-digest` writes into through Operator MCP; `hivemind-capture` and the
field guides name it too. The project-docs skill audit (2026-09) found that
retirement doesn't apply to HiveMind's folder and left the decision to the
hivemind plugin.

## Definition of done

- [ ] A decision on whether HiveMind keeps a Lessons Learned folder, recorded
      here, and, if it goes, the skills that name it changed.
